# Security policy

## Supported versions

Security fixes are intended for the current default branch. No separate long-term support versions are documented.

## Reporting a vulnerability

Please do not publish exploit details in a public issue. Use GitHub's private vulnerability reporting for this repository (Security → Advisories → Report a vulnerability) when available. Include affected paths/versions, impact, and steps to reproduce without exposing real credentials or third-party data.

If private reporting is not enabled, contact the repository maintainer privately through the GitHub account before disclosure. Acknowledgment and remediation timelines are not yet documented.

This research project is not an operational forecasting service. Do not submit sensitive datasets or credentials as vulnerability evidence.
